# VaPicha landing page

A responsive Next.js App Router landing page using the supplied company content and original logo. Brand colors: deep blue `#0E3E60`, teal `#148F7B`, green `#2A9B5F`.

## Run

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
```

The project exports a static website to `out/`, deployable on any static host. For Vercel, use the Next.js framework preset.

The portfolio chart and application examples are illustrative. Institution tabs and chart period selection work locally. Demo requests open the visitor's email application; they are not stored or sent by a server. Contact addresses and pricing come from the supplied HTML. Unverified market statistics have been omitted. Fonts load from Google Fonts, with local sans-serif fallbacks.
